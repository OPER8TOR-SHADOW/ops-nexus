# OPS Nexus Agent Rules

1. Do not redesign architecture.

2. Do not modify unrelated pages.

3. One feature per session.

4. No automatic dependency installation.

5. No helper scripts committed to the repository.

6. Remove temporary scripts after use.

7. Do not add tests unless requested.

8. Never refactor working code unless asked.

9. Always run the application after UI changes.

10. Always provide screenshots after UI work.

11. If scope needs to expand, stop and ask first.
